# NasTools UI 概念原型 · 01

**此原型已被用户选为后续 UI 设计基准。** 确认范围、文件摘要及待补场景见 [BASELINE.md](./BASELINE.md)。开发必须遵守 [原型优先契约](../../.trellis/spec/frontend/prototype-first.md)，不能把演示逻辑直接用于生产。

直接用 Chrome / Edge 打开 `index.html`，无需安装依赖或启动服务器。保留整个目录，HTML 会读取同目录的 CSS、JS 与本地图片。

## 设计方向

- 雾白底色、松绿强调色、石墨文字；另有完整深色主题。
- 连接、文件、传输、设置四个底部入口。上传预设从首页与设置进入。
- 桌面展示手机预览及设计说明；小于 740px 时成为全屏手机界面。
- 明确区分传输中、已暂停、等待中、完成、失败、取消，状态不单靠颜色表示。
- 保留真实产品的 WebDAV、上传预设、同名文件策略、任务控制与权限说明等核心概念。

## 已有页面与交互（v1.1 范围 A 基准）

1. 连接首页：浏览、新建、编辑、删除演示连接（删除含级联预设提示）。
2. 连接选择：文件入口未选连接时显示；删除当前连接后回退。
3. 文件浏览：多层目录面包屑、列表/网格、新建文件夹、删除；首次加载失败与刷新失败（保留旧列表）两种状态。
4. 媒体预览：本地样例图片、前后切换、加载失败重试、文件信息；视频条目可选择本地视频播放。
5. 上传流程：文件/文件夹来源、同名文件五策略、同名文件夹四策略、移动上传、保存为预设。
6. 任务中心：活跃/完成/失败筛选、多选批量删除、暂停、恢复、重试、跳过/过滤警告、总量未知不定进度。
7. 任务详情：进度、数据、文件明细、二次确认取消或删除。
8. 连接编辑：字段验证、模拟连接测试、保存、未保存离开确认。
9. 上传预设：新建、编辑、删除、运行预设、高级选项、未保存离开确认。
10. 设置：模拟权限状态、重置演示（主题跟随系统，无手动切换入口）。

## 演示边界

- **不连接真实 NAS，不上传文件，不读取本地目录，不保存密码。**
- 数据只在当前页面内存中保存，刷新后恢复初始值。
- 搜索、类型筛选、重命名、手动主题偏好已按范围 A 从基准移除，留待后续规划。
- 传输数据、速度、剩余时间与连接测试均为模拟，不自动递增。
- 权限操作只改变演示状态，不能改变 Android 系统权限。
- PDF / 音频展示文件信息，不提供播放器或阅读器。
- 默认跟随系统主题，桌面预览工具栏可切换用于验收。
