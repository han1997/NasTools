# 首页与文件页 UI 修复及页面切换闪屏消除

来源：用户 2026-10-11 真机体验反馈，共三点。属于父任务「体验与功能优化」的新增子任务。

## Goal

1. 彻底消除所有页面切换（底部四个主标签之间、主页↔子页面）时的闪屏现象；用户明确表示「不希望看到这种现象」。
2. 按 `prototypes/nastools-ui/` Concept 01 原型对齐首页 UI。
3. 文件页列表模式下，文件夹改为单列列表行（与文件一致的列表形式）。

## Background（已查证）

### 闪屏
- `NavGraph.kt` 已改为 150ms 交叉淡化，但真机上标签切换仍闪出背景色。
- `HomeScreen.kt` 内容列使用 `nasAnimateContentSize`，加载态→内容切换时高度突变。
- 主页面间切换使用 `navigateTab`（popUpTo + saveState/restoreState），切换时整个 `NavHost` destination 重建重绘。
- 具体根因（窗口背景 vs 转场空白）需在实施中用编译验证 + 用户真机确认收敛。

### 首页与原型差异（`app.js homeView()` vs `HomeScreen.kt`）
| 项 | 原型 | App 现状 |
|---|---|---|
| 顶部标语 | 无（仅顶栏 NasTools/你的私人文件空间） | 多了「一切，都在这里。」「连接你的 NAS，随时接着上一次。」 |
| 分节标题 | 「我的连接 <count>」+ 右侧「WebDAV」 | 「连接」+「N 个配置」 |
| 常用工作流 | 有「常用工作流」区块 + 上传预设快捷入口 | `PresetShortcut` 组件已实现但从未使用 |
| 连接卡菜单 | 编辑连接 + 删除连接（删除有级联预设确认） | 仅编辑连接 |
| 加载态 | 骨架屏（原型有 skeleton） | 已有骨架屏，保留 |

### 文件页文件夹显示
- `BrowserScreen.kt` 列表模式下文件夹为两列 `FolderCard` 网格；用户要求改为单列列表行。
- 注意原型 `.folder-grid` 也是卡片网格，但用户已明确选择单列列表行——以用户为准，属有意的偏离原型。

## Requirements

### R1 页面切换闪屏消除
- 底部四个主标签（连接/文件/传输/设置）之间切换无闪屏、无背景色闪现。
- 主页面与子页面（连接编辑、任务详情、上传预设、媒体预览）之间进出无闪屏。
- 不得退回「删除转场导致硬切」以外的方案时引入新的视觉跳动。
- 沿用 `presentation/theme/` token 与 `AppChrome.kt` 组件，不新造平行体系。

### R2 首页对齐原型
- 移除「一切，都在这里。」及其副标题两行。
- 分节标题改为「我的连接 <count>」，右侧 meta 为「WebDAV」。
- 新增「常用工作流」区块，接入已有的 `PresetShortcut`（点击进入上传预设）。
- 连接卡片菜单补「删除连接」：复用 `NasConfirmDialog`，文案需说明会级联删除相关上传预设、NAS 文件不受影响；删除后若为当前会话选中连接，清理 `FileTabSession` 选择。
- 保留 ActiveTaskBanner（原型设计说明允许传输状态独立出现）。

### R3 文件夹单列列表行
- 列表模式下文件夹与文件统一为单列列表行（复用 `EntryRow` 样式，图标为文件夹），含分隔线、长名省略、更多菜单（删除）。
- 网格模式行为不变。
- 删除确认、空目录、加载失败等状态行为不变。

## Acceptance Criteria

- [ ] AC1 真机验收：四个主标签来回切换及进出子页面，肉眼看不到闪屏/背景闪现（用户确认）。
- [ ] AC2 首页文案、分节标题、常用工作流区块与原型一致；PresetShortcut 正常跳转上传预设页。
- [ ] AC3 首页连接卡片可删除连接；确认对话框文案包含级联提示；删除后相关预设一并删除，当前文件会话回退到选择连接页。
- [ ] AC4 文件页列表模式文件夹为单列列表行；点击进入目录、删除、面包屑导航正常。
- [ ] AC5 `./gradlew assembleDebug` 编译通过；现有单元测试通过。
- [ ] AC6 遵守 `.trellis/spec/frontend/prototype-first.md` 原型优先契约；偏离原型处（R3）在本 PRD 有记录。
