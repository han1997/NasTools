# 原型驱动的全应用 UI 重设计

父任务：`10-01-experience-feature-optimization`。复用原 `10-01-ui-polish`，不重复创建美化任务。
状态：**规划中，尚未批准进入实施**。

## Goal

以用户确认的 `prototypes/nastools-ui/` Concept 01 为设计基准，将现有 Android 应用迁移到松绿 / 雾白 / 石墨的原生 Compose UI，并建立所有后续 UI 开发必须遵守的原型优先契约。

## Confirmed decisions

- 用户已选择当前 HTML 原型作为 UI 基准，并批准进入规划、补充上一轮建议的全部规则。
- 原型未覆盖的页面、组件、交互与必要状态，必须先补原型，经用户确认后再实现。
- 使用原生 Compose，不以 WebView 嵌入 HTML。
- 迁移现有功能，不移植假数据、假成功、演示权限、手机外框和桌面展示侧栏。
- 现有功能不能因原型未呈现而删除；新功能不能因出现在原型里而默认批准开发。
- 用户选择范围 A：本轮只迁移现有功能的全套 UI 与导航，先补原型漏项；搜索/类型筛选/重命名/手动主题偏好后续独立规划，正式应用继续跟随系统明暗主题。
- 新的范围替代旧 PRD 的「视觉方向未定」「导航调整不在范围内」和「必须等排序筛选完成」条件；排序筛选任务仍保持 planning，不因此视为完成。
- 用户采用子页面导航规则：底部导航仅出现在连接/文件/传输/设置四个主页面；连接编辑、预设列表/编辑、任务详情、媒体预览等子页面隐藏底部导航，用顶部或系统返回回到实际来源页并保留来源状态。
- 用户采用未保存编辑保护：连接/预设表单内容与进入时不同（含改回原样的简化比对）时，顶部返回或系统返回先弹确认，文案写明「未保存的修改将会丢失」，提供「离开/继续编辑」；保存或删除成功后正常返回不再提醒；测试连接不算改动。

## Requirements

| ID | 要求 |
|---|---|
| R1 | 建立原型优先规范，覆盖确认门槛、版本、功能对照、状态矩阵、原生适配、视觉验收与同步变更。 |
| R2 | 所有现有主要页面采用已确认原型的视觉语言：连接、浏览、上传配置、任务列表/详情、连接编辑、预设列表/编辑、媒体和设置。 |
| R3 | 采用连接 / 文件 / 传输 / 设置的四入口。连接选择、子页面导航与未保存编辑保护规则均已确认（见 Confirmed decisions）；上述场景仍须补原型并评审。 |
| R4 | 复用并调整 `presentation/theme/` 与 `AppChrome.kt`，不建立第二套主题或页面私有样式系统。 |
| R5 | 原型缺失的既有上传选项、批量操作、错误和警告状态先补齐；保留上传、续传、冲突策略、移动上传、安全删除和远端媒体等真实行为。 |
| R6 | 各页面覆盖加载、内容、空、错误/重试、操作执行/失败、选中/禁用及危险确认；无适用状态须记录理由。 |
| R7 | 浅深主题、320/390dp 窄屏、较宽窗口、大字体、长路径、多层目录、键盘及系统栏适配；交互热区不小于 48dp。 |
| R8 | 不依赖颜色单独传递状态；图标有可访问名称；未知速度/总量/剩余时间显示未知或不定进度，不编造指标。 |
| R9 | 遵守范围 A：本轮不实现新增搜索、类型筛选、重命名、手动主题偏好或远端缩略图加载；保留已有列表/网格、任务状态分组和远端媒体预览。不承担后台能力改造、全项目字符串资源化或凭据加密。 |
| R10 | 原型、规范、Compose 预览与验收截图保持可追溯；所有未达成项明确标为待验收，而非以构建通过替代视觉验收。 |

## Acceptance criteria

- [ ] AC1（R1/R9/R10）：规范与入口索引可发现；原型基线、确认范围、后续修改与例外有记录。
- [ ] AC2（R2/R4）：全页面视觉迁移完成，使用集中 token / 共享组件；旧规则与新基准冲突被明确处理。
- [ ] AC3（R3）：四入口无重复页面堆栈；底部导航仅在四个主页面出现，子页面返回实际来源并保留来源状态（如设置→预设→返回设置、文件→图片→返回原目录位置、任务列表→详情→返回原分组位置）。连接/预设表单有未保存改动时，顶部与系统返回均先确认再离开，保存/删除成功后不提醒。连接选择至少覆盖：未选且仅一台也显式选择、无连接引导新建、已选目录恢复、手动切换、当前连接删除后清理回选择页、暂时断网保持当前连接并重试；任何错误不得自动切换到其他 NAS。
- [ ] AC4（R5/R9）：功能对照表无遗漏既有能力；未纳入的新功能不得呈现可点但无真实行为的正式按钮。
- [ ] AC5（R6/R8）：阻塞错误可重试；刷新失败保留旧列表；操作失败可见；危险确认取消不执行、确认只执行一次；任务六态仍可区分。
- [ ] AC6（R7/R8）：各页明暗截图、窄屏与字体放大检查完成，系统栏/键盘不遮挡主要动作。
- [ ] AC7（R5/R10）：编译、JVM 单测、lint 通过；上传及远端媒体回归有证据；缺设备/网络造成的阻塞明确记录。
- [ ] AC8（R10）：用户完成原型补充确认与 Android 视觉验收；没有把原型冒烟测试当作真机验收。
